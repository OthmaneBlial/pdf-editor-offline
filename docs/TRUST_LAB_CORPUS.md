# Synthetic compatibility corpus

The public corpus in [`trust_lab/corpus/v1`](../trust_lab/corpus/v1) contains no customer or real-world documents. Every fixture is generated by [`pdf_editor_offline/trust_lab/corpus.py`](../pdf_editor_offline/trust_lab/corpus.py), and CI verifies that the checked-in manifest exactly matches a fresh generation.

## Version 1 coverage

| Fixture | Structure under test | Expected behavior |
| --- | --- | --- |
| `forms.pdf` | Text, checkbox, and dropdown AcroForm widgets | Preserve or warn before flattening/removal |
| `mixed-fonts.pdf` | Four built-in font/style combinations | Preserve or report substitution/removal |
| `image-scan.pdf` | Image-only scanned page | Render locally; OCR remains explicit and optional |
| `layers-transparency.pdf` | Optional-content group, vector drawing, alpha transparency | Preserve or report flattening |
| `rotated-page.pdf` | 90-degree page rotation | Preserve |
| `bookmarks.pdf` | Multi-level outline and reading sequence | Preserve or report removal |
| `attachment.pdf` | Inert plain-text embedded file | Preserve or report removal |
| `signed.pdf` | Real detached CMS signature over a PDF signature field | Detect before any byte-changing operation and warn that validity may be lost |
| `malformed.pdf` | Broken reference, xref, and trailer | Reject safely |

The signing factors and certificate are intentionally public test material. They must never be used for a real document. The signature exists to exercise detection and invalidation behavior, not to establish identity or trust.

Regenerate the corpus from the repository root:

```bash
PYTHONPATH=. python scripts/generate_trust_lab_corpus.py
```

Generation is byte-reproducible, including the attachment timestamps and RSA CMS signature. `manifest.json` records only fixed case metadata, sizes, page counts, and SHA-256 hashes.

## Change-review tolerance

[`compare_pdf_files`](../pdf_editor_offline/core/change_review.py) renders both documents at 144 DPI by default. A pixel is changed when its grayscale delta is greater than 12. A page is outside tolerance when more than 0.1% of pixels outside caller-declared expected regions change.

The report contains no extracted text, metadata values, filenames, or paths. It records:

- per-page changed-pixel ratio and bounding box outside expected regions;
- counts of added/removed characters and changed metadata keys;
- before/after structure counts;
- warnings for font substitution/removal, flattening, rasterization, accessibility-tag loss, signature invalidation, bookmark loss, attachment removal, and layer flattening;
- input/output SHA-256 hashes and fixed overlay artifact names.

Expected regions are expressed in PDF points and are used only as a mask. A completely untouched page must remain at a zero changed-pixel ratio in regression tests.
