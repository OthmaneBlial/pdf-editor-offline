# PDF Editor Offline 3.0.0 — unsigned desktop preview

> **Technical preview only. These installers do not satisfy native platform
> signing gates and are not the stable 3.0.0 release.**

This owner-authorized preview makes the clean-runner desktop builds available
without pretending that unavailable certificates exist. It is published as a
GitHub **pre-release**, is never selected as the latest stable release, and does
not weaken the separate signed production workflow.

## Native trust status

| Platform | Asset | Native trust status |
| --- | --- | --- |
| Windows 10/11 x64 | `PDF-Editor-Offline-3.0.0-windows-x64-setup.exe` | Unsigned; no Authenticode publisher or trusted timestamp. Windows may warn or refuse to run it. |
| macOS 11+ Apple Silicon | `PDF-Editor-Offline-3.0.0-macos-arm64.dmg` | Ad-hoc build; no Developer ID and not notarized. Gatekeeper may refuse to run it. |
| macOS 11+ Intel | `PDF-Editor-Offline-3.0.0-macos-x64.dmg` | Ad-hoc build; no Developer ID and not notarized. Gatekeeper may refuse to run it. |
| Ubuntu 22.04/24.04 x64 | `.AppImage` and `.deb` | Linux has no project-native platform signature; use SHA-256 and GitHub provenance. |

Do not disable operating-system security controls solely to run this preview.
Users who require native publisher identity or notarization should continue
using the source/PyPI/Docker channels or wait for a future signed release.

## What is verified

- Every asset is built from the release commit on its declared clean GitHub
  runner.
- The frozen local sidecar completes `upload → redact → export → reopen`.
- The packaged app is installed, launched, checked for exact-child cleanup, and
  uninstalled or removed on the target operating system.
- `SHA256SUMS` covers every installer, four CycloneDX SBOMs, four offline
  Sigstore provenance bundles, the synthetic sample pack, this notice, and the
  combined manifest.
- GitHub-hosted provenance is reverified immediately before publication.
- Large intermediate Actions artifacts are removed after the remote asset set
  is verified; the downloadable release assets, checksums, manifest, SBOMs, and
  provenance remain attached to this pre-release.

Verify a downloaded installer with:

```bash
sha256sum --check SHA256SUMS
gh attestation verify PDF-Editor-Offline-3.0.0-windows-x64-setup.exe \
  --repo OthmaneBlial/pdf-editor-offline
```

On macOS, use `shasum -a 256 --check SHA256SUMS`. On Windows, use
`Get-FileHash -Algorithm SHA256` and compare the exact line in `SHA256SUMS`.
