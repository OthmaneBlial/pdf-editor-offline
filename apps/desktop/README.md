# Native desktop milestone

```sh
cargo run -p pdf-editor-offline-native
```

Eframe/egui 0.36.2 provides a native accessible widget tree and window; rfd provides native file dialogs. The app does not launch Python, a web server, a webview, or a remote renderer. PDFs are parsed with `pdf-core` and rasterized with `pdf-render` on one background worker. A one-slot command channel and one active UI request prevent render-request accumulation. Page, zoom, document and revision keys discard stale results.

Open up to 16 PDF tabs, navigate pages, zoom, change dark/light theme, rotate the current page, undo/redo, and Save As. The workstation has a resizable Pages/Search/Text sidebar, a document/page inspector, a centered page canvas, real action menus, a command palette and bottom status/navigation. The inspector collapses below a 960-point window width; extracted text remains available in the sidebar. Original paths are never overwritten. Save uses the core's validated, no-clobber atomic write. Signed and encrypted inputs are read only. Password entry, signing, OCR, redaction, forms, arbitrary text editing and conversion are not implemented by this milestone. A successful preview does not establish PDF fidelity; unsupported content may be omitted by Hayro.

Search extracts actual text one page at a time on the worker and matches a literal query, with optional case sensitivity. Case-insensitive matching uses Unicode lowercase equivalence. Results select the matching page and show an original-text excerpt; they do not invent page-coordinate highlights. Searches stop at 200 matching pages, queries allow 256 characters, and page text is capped at a UTF-8 boundary within 1 MiB. The UI reports partial search/text limits. A read-only selectable page-text control exposes the extracted text through the widget accessibility tree; actual platform screen-reader behavior remains unverified. Search generation, document and revision keys discard stale results. New page renders take priority over subsequent search pages.

An unmodified 1.2 MiB Noto Sans Symbols 2 font is embedded offline as the final proportional/monospace fallback, leaving ordinary typography unchanged. It supplies the `✓` checkmark seen in extracted text. The pinned official Google Fonts source, SHA-256 and required OFL notice are in [font provenance](assets/fonts/PROVENANCE.md). Native release artifacts must include `assets/fonts/OFL.txt`. The fallback does not guarantee every Unicode script.

Closing a modified tab or quitting with unsaved changes prompts before discarding. Save failures keep the edits and document open. Main preview caches retain at most 64 MiB of RGBA pixels across tabs, evicting other tabs when necessary; this counts pixel payloads, not driver allocations or transient copies. Up to eight history snapshots are retained, within an additional 256 MiB budget measured by serialized bytes. That is an estimate of clone memory, not a hard process-memory limit. Input/output limits and an in-process thread do not contain malicious parser/decompression failures; a resource-limited subprocess remains required for hostile-file isolation.

Page rasterization uses logical document zoom × the window's physical pixels-per-point ratio. A Retina display therefore renders two pixels per logical point at 100% zoom, while the canvas divides the raster size by that ratio. Device ratio, logical zoom and actual raster scale are part of each request key; monitor/DPI changes invalidate stale cached or pending images. The visible CropBox/MediaBox intersection and page rotation determine a safe raster plan. Output remains limited to 8192 pixels per side and 16,777,216 pixels total. If the requested physical resolution would exceed those bounds, the raster resolution is reduced while desired logical page size and zoom remain unchanged, and the canvas reports the resolution limit.

Keyboard: Command/Ctrl+O opens, Command/Ctrl+S saves a new copy, Command/Ctrl+Z undoes, Command/Ctrl+Shift+Z redoes, Command/Ctrl+W closes a tab, Command/Ctrl+F shows Search, Command/Ctrl+K opens the command palette, Command/Ctrl+Q quits, and left/right arrows change pages when no widget has keyboard focus. File → Quit, the Quit palette action, the keyboard shortcut and the window close button share the same unsaved/busy-operation guard. The palette supports a filtered working-action list, Enter to execute the first enabled match, and Escape to dismiss.

On macOS, Winit's default native application menu is disabled because its Quit command directly terminates the process before the unsaved-change guard runs. The application's File → Quit action and logical Command+Q shortcut use the guarded route, verified with a real dirty document. Native Dock/system termination is a separate unverified path.

Twenty tests cover state/history, stale results, no-clobber saving, real-PDF search, case/Unicode matching, UTF-8 and result limits, completion/Stop state and the pinned fallback glyph. Actual macOS search, `✓` display, completion status, palette actions, theme changes and guarded quit are recorded in [runtime evidence](../../docs/NATIVE_DESKTOP_EVIDENCE.md). Accessibility activation/value assignment did not reliably focus or update the search input; clicking the visible field and pasting worked. Exposed document text is not a complete screen-reader audit.

DPI tests exercise physical 2× rendering of a real synthetic PDF, unchanged logical display dimensions, DPI-stale result rejection, crop/rotation, nonfinite input rejection and exact ceiling-aware output limits. Retina sharpness was visually checked on macOS; multimonitor transitions and oversized-document limit messaging remain unverified at runtime.
