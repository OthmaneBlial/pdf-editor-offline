# Feature status and product roadmap

The old completed-feature checklist has been retired. A visible control or an
HTTP endpoint is not enough to call a PDF capability complete.

- Read [the capability matrix](docs/CAPABILITIES.md) for the current, tested
  status of stable, beta, experimental, external-dependency, and unsupported
  capabilities.
- Read [the delivery roadmap](ROADMAP.md) for planned work and phase exit gates.
- Read [known limitations](docs/KNOWN_LIMITATIONS.md) before processing
  sensitive or structurally complex documents.

The capability matrix is the public product contract. It must be updated with
tests and user-facing limitations whenever support changes.
