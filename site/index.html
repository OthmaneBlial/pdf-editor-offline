For developers and self-hosters

Run it your way.

Start the visual editor locally, install the CLI, or reuse the Python and FastAPI layers.

Complete local app
git clone https://github.com/OthmaneBlial/pdf-editor-offline.git
cd pdf-editor-offline
pip install -e ".[dev]"
./start.sh
CLI and Python package
pip install pdf-editor-offline
pdf-editor-offline --version
Docker API
docker pull othmaneblial/pdf-editor-offline
