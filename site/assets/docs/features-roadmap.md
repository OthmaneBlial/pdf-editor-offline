# Feature status and product roadmap

The old “all features complete” checklist has been retired. A visible control
or HTTP endpoint is not sufficient evidence that a PDF capability is complete.

- Read the [capability matrix](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/docs/CAPABILITIES.md) for current tested status.
- Read the [delivery roadmap](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/ROADMAP.md) for planned work and phase exit gates.
- Read [known limitations](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/docs/KNOWN_LIMITATIONS.md) before processing sensitive or structurally complex documents.

The capability matrix is the public product contract. Status changes require
automated evidence and updated user-facing limitations.
