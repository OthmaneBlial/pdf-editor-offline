# PDF Editor Offline documentation

This portable site copy intentionally does not duplicate the full project
README. Product claims, setup commands, and security boundaries change more
often than the static showcase.

- Read the [canonical project README](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/README.md).
- Check the [capability matrix](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/docs/CAPABILITIES.md) before relying on a workflow.
- Read the [privacy contract](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/docs/PRIVACY.md) and [known limitations](https://github.com/OthmaneBlial/pdf-editor-offline/blob/main/docs/KNOWN_LIMITATIONS.md) for sensitive documents.

For source mode, use `./start.sh`. It selects random loopback ports, creates a
per-launch API token, and stops only the child processes it owns.
