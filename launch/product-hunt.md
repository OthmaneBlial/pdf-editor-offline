## Description

PDF Editor Offline is a free, open-source PDF editor that runs on your
computer. Edit, sign, annotate, merge, convert, OCR, and redact documents
without uploading them. No account, no document telemetry, and no Adobe
subscription.

The description is 230 characters, so it fits both the 260-character limit
documented in Product Hunt's help center and the newer 500-character limit in
its launch guide.

## Maker's first comment

Hey Product Hunt 👋

I built PDF Editor Offline because opening a sensitive PDF
shouldn't mean uploading it to someone else's server or starting another
subscription.

It runs on your computer and lets you edit, fill and sign, annotate, organize
pages, convert, OCR, and permanently redact sensitive text. The project is free,
MIT-licensed, and doesn't require an account or document telemetry.

The desktop app is currently an unsigned technical preview, so Windows and
macOS may show security warnings. You can also run the full visual editor from
source, and the Python package and CLI are on PyPI.

I'd especially value feedback on:

- Which everyday PDF task would you try first?
- Is the local-only privacy promise clear?
- What would make you trust an open-source PDF editor for real work?

Please use a synthetic or non-sensitive PDF when testing the preview. Thanks!
